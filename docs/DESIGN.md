# Trick or Trivia 2026 — Visual Design

## Creative direction

**Campy Haunted Game Show**: a spooky live Halloween television special hosted from a haunted porch. The experience is adult-forward, theatrical, playful, readable from a distance, and welcoming to players age 8 and older without feeling childish.

## Core principles

- Bold game-show clarity before decoration
- Spooky and theatrical, never graphic or disturbing
- Large type and high contrast for porch viewing
- Simple, generous touch targets for player phones
- Main game uses classic Halloween showmanship
- Dungeon Crawler Carl bonus floors use a distinct green system-override treatment

## Palette

- Midnight Black `#0f0b14`
- Charcoal Plum `#1d1326`
- Deep Violet `#2c1740`
- Pumpkin Orange `#f47b20`
- Electric Purple `#9a5cff`
- Eerie Green `#9cff57`
- Moonlight Cream `#f6eedb`
- Candle Gold `#f6c453`
- Warning Red `#e24a55`

## Typography

- Display: Creepster for major haunted-show titles only
- Condensed show lettering: Barlow Condensed
- Interface and question copy: system sans-serif fallback stack

## Voice

Preferred phrases include **Choose Your Doom**, **Answer If You Dare**, **The Dungeon Is Open**, **Tonight’s Survivors**, **Bonus Floor Unlocked**, and **The Spirits Approve**.

## Privacy

The home address is never committed to the public source. It is entered in Host Controls, hidden by default, and displayed only while the host enables the public-address setting.
