# Online Test Checklist

## Test devices

- One laptop or tablet for Host Controls
- One television or second browser for Porch Display
- At least two phones for Player View
- One private/incognito browser to simulate a brand-new visitor

## Connection test

- Every device shows `Live room CARL26`
- Host Controls show `Live Host — Quizmaster Tara`
- Player names appear on the host screen and leaderboard
- A newly joined player appears without refreshing

## Question test

- Host selects a question
- The same question opens on all devices
- Countdown stays approximately aligned
- Each phone can submit one answer and change it before time expires
- Host sees the live answer count
- Reveal appears on all devices
- `Score Correct Answers` updates all correct players only once
- Returning to the board closes the question everywhere
- Used tiles show `Conquered`

## Game controls

- New round resets round scores but preserves night totals
- Restore Question Board clears used tiles
- Clear Test Players removes player entries
- DCC Bonus Floor triggers the green system-override treatment everywhere

## Privacy test

- Address remains absent while the toggle is off
- Host can enter an address without it appearing publicly
- Enabling the toggle shows the address on the display
- Disabling the toggle removes it immediately
- A player account cannot read the private address path

## Failure test

- Refresh one phone during a question
- Close and reopen a player browser
- Briefly disable Wi-Fi, then reconnect
- Try answering after the timer reaches zero
- Try scoring the same question twice
- Try opening Host Controls from a non-host phone
